# Exercício de Estruturação com HTML - EBAC

Este repositório contém o exercício prático focado na criação de uma página web utilizando apenas HTML5 estrutural.

## O que foi desenvolvido:
* **Marcação Semântica:** Uso de tags adequadas para definir a hierarquia e o significado do conteúdo.
* **Estruturação de Conteúdo:** Organização de textos, listas, links e imagens.
* **Acessibilidade:** Uso de atributos obrigatórios para garantir uma melhor experiência de navegação.
* **Versionamento:** Prática do fluxo de trabalho Git utilizando a branch `exercicio_html`.

## Tecnologias:
* HTML5
* Git / GitHub
