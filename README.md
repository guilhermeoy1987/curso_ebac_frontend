
# Exercício de Criação de Formulários - EBAC

Este projeto foca na estruturação e validação de formulários web, uma parte essencial para a comunicação entre o usuário e o sistema.

## O que foi desenvolvido:
* **Estrutura de Formulário:** Uso de campos variados para coleta de informações (texto, e-mail, telefone).
* **Validação Nativa:** Implementação de regras de preenchimento obrigatório e máscaras básicas via HTML5.
* **Acessibilidade:** Associação correta de labels e campos para leitores de tela e usabilidade.
* **Estilização de Interface:** Organização visual dos campos e botões utilizando CSS.

## Tecnologias:
* HTML5
* CSS3
* Git / GitHub (Branch: tarefaformulario)
