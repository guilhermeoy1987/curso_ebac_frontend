# Exercício de Git e GitHub - EBAC

Este exercício teve como objetivo principal a prática das rotinas de versionamento de código em um ambiente de desenvolvimento front-end.

## O que foi realizado:
* **Criação de Branches:** Criação da branch `exercicio_git` para desenvolvimento isolado.
* **Versionamento:** Uso de comandos Git para realizar commits e push das alterações.
* **Pull Requests:** Abertura de um PR para integração de código, simulando o fluxo de revisão em equipe.
* **Documentação:** Atualização do README com as informações do projeto.

## Tecnologias:
* Git
* GitHub
