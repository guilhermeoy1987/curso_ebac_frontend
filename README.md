
# Projeto Landing Page GameShop

Este projeto integra os conhecimentos de HTML5 e CSS3 para criar a interface de uma loja virtual de jogos (GameShop), focada em layout e organização de produtos.

## O que foi realizado:
* **Estruturação de Vitrine:** Criação de cards de produtos com informações de preço, plataforma e botões de ação.
* **Layout e Design:** Aplicação de estilos CSS para criar uma identidade visual temática e atraente.
* **Componentização Visual:** Organização de seções de destaque e rodapé institucional.
* **Boas Práticas de Código:** Uso de marcação semântica e folha de estilos organizada.

## Tecnologias:
* HTML5
* CSS3
* Git / GitHub (Branch: sitegameshopp)
