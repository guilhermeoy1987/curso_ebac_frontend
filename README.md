
# Projeto Game Shop - EBAC

Este projeto consiste na criação de uma página de loja virtual focada no nicho de jogos, desenvolvida durante o curso de Front-end da EBAC.

## O que foi desenvolvido:
* **Interface de Vendas:** Estruturação de uma vitrine de produtos com foco em experiência do usuário.
* **Estilização Customizada:** Uso de CSS para criar uma identidade visual temática de games.
* **Componentização:** Organização de itens de produtos (cards) com títulos, imagens e preços.
* **Fluxo de Trabalho:** Desenvolvimento isolado na branch `gameshop`, seguindo boas práticas de versionamento.

## Tecnologias:
* HTML5
* CSS3
* Git / GitHub
