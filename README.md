
# Exercício de Integração HTML e JavaScript

Este projeto demonstra a aplicação de lógica de programação para criar interatividade em uma página web.

## O que foi desenvolvido:
* **Manipulação do DOM:** Uso de JavaScript para interagir com elementos HTML em tempo real.
* **Gestão de Eventos:** Implementação de funções disparadas por ações do usuário (cliques e submissão de formulários).
* **Validação de Dados:** Lógica básica para processar informações inseridas pelo usuário.
* **Estrutura Semântica:** Uso de HTML5 para criar a base da interface de interação.

## Tecnologias:
* HTML5
* JavaScript (ES6+)
* Git (Trabalho com branches)
